# PinUI Component Attribution

The components in this directory are adapted for the F-FORUM v3 Obsidian Foundry & Editorial Stone token system from the open-source PinUI registry and blocx library (MIT License, https://www.pinui.xyz):

- `PromptComposer` (`registry/prompt-composer`)
- `LiquidTabs` (`registry/liquid-tabs`)
- `SearchCard` (`registry/search-card`)
- `ThemeSwitch` (`registry/theme-switch`)
- `Chips` (`registry/chips`)
- `TaskCard` (`registry/task-card`)
- `FileBox` (`registry/file-box`)
- `PresenceCards` (`registry/presence-cards`)
- `DynamicDropZone` (`registry/dynamic-drop-zone`)
- `HaloSignIn` (`blocx/halo-sign-in`)
- `SynaisFooter` (`blocx/synais-footer`)

All demo assets, third-party avatar URLs, and Next.js font imports were replaced with native CSS custom properties, inline geometric SVGs, and F-FORUM v3 state hooks.
